# Windows 虚拟 COM

[English](windows-virtual-com.md) | [简体中文](windows-virtual-com.zh-CN.md) · [README](../README.zh-CN.md)

只认 COM 口的程序需要内核驱动来创建串口。本项目不附带驱动，只管理你自行安装的两款产品。两款都在 Windows 11 23H2 上测试过，Secure Boot、驱动签名强制和内存完整性均保持默认开启。不要为本项目关闭这些保护。

## 选择驱动

| | HW VSP3 Single 3.1.2 | com0com 3.0.0.0 签名版 + 桥接 |
| --- | --- | --- |
| 数据路径 | COM → 驱动自带 TCP 客户端 → 端点 | COM ↔ 端口对隐藏端 → 本程序桥接 → 端点 |
| 二进制数据、打开时的参数 | 支持 | 支持 |
| 打开后修改波特率 | 仅 57600 及以下 | 支持（已测 1.5 Mbaud） |
| 修改数据位 / 校验 / 停止位 | 只有同时改波特率才下发 | 支持 |
| DTR / RTS / BREAK | 不转发 | 转发 |
| PURGE | 不转发 | 不转发 |
| 会话结束 | 应用关闭串口时 | 应用关闭串口时（关闭检测） |

Bootloader 通常会切换 DTR/RTS 复位芯片，握手后再切换波特率，这类场景请选 com0com。只需固定速率传数据时，HW VSP 就够用。

## HW VSP3 Single

1. 从厂商官网下载 HW VSP3 **Single** 版并安装，自行确认许可条款；本项目不再分发它。
2. 在程序中打开 **虚拟 COM** 页，点击“刷新检测”。设置 COM 名称（默认从 COM10 起第一个空闲号）、主机 `127.0.0.1`、端口为网关的监听端口，保持勾选“RFC2217”。
3. “预览配置”只显示将要写入的 `CHANNEL0` 段。厂商的 `[GENERAL]` 段（含密码）不会被复制或修改。
4. “应用到 HW VSP”会弹出一次管理员确认。程序会先备份厂商 INI，然后停止服务、写入通道、重启服务，并关闭“自动重连”和“端口未打开时也连接”。

厂商模板自带的示例通道（`Demo`、`COM3`、`:23`）会在页面上标出，因为它的 COM 名常与实体串口冲突。

HW VSP 只解析它自己发出的 RFC2217 请求的回复。服务器主动发送的 Telnet 选项协商或调制解调器通知，会被当作数据交给你的应用。所以网关和 ESP32 库默认使用安静模式。

## com0com

1. 从项目的 SourceForge 下载页安装**签名版** `com0com-3.0.0.0-i386-and-x64-signed`。安装程序的 Authenticode 签名应显示有效（签名者 *CyberCircuits*）。
2. 在 **虚拟 COM** 页点击“新建端口对…”，选择一个空闲名称，例如 `COM11`。确认一次管理员提示后会创建 `COM11 ↔ CNCBn`：你的应用使用 `COM11`，桥接打开隐藏的 `CNCBn`。
3. 本程序创建的端口对自带**关闭检测**：隐藏端的 RI 线反映“应用端是否已打开”（`ri=ropen`）。如果端口对是用其他方式创建的，选中后点击“启用关闭检测”。
4. 在 **com0com 桥接** 页选择端口对，填写目标地址（ESP32；本机测试时填 `127.0.0.1` 和网关端口），点击“启动桥接”。

桥接的工作方式：

- 通过驱动的带内插入记录（扩展 `IOCTL_SERIAL_LSRMST_INSERT`）读取应用设置的波特率和线路参数，打开后再修改也能读到；
- 在隐藏端把 DTR/RTS 读成 DSR/CTS，把 BREAK 读成线路状态记录；
- 每个变化转成一条 RFC2217 请求，不主动发送 Telnet 协商；
- 正常应答服务器的协商，因此也兼容标准 RFC2217 服务器；
- 以 8N1 二进制方式打开隐藏端。新打开的 COM 默认是 7 位数据位，而 com0com 会按接收端的位宽截断数据，否则每个字节的最高位都会被悄悄清掉。

没有关闭检测时，桥接分不清“串口已关闭”和“DTR 脉冲”，会话会一直保持。只凭 DTR 永远不会判定为关闭，因为烧录工具会故意拉 DTR 脉冲。

## 重新连接

会话结束后，网关拒绝新客户端，直到你点击“重新就绪”；桥接页会显示“重新开始”。先关闭应用的 COM 口。旧的缓存数据不会续传到新会话。

## 不接硬件的检查

```powershell
python -m serial_gateway vcom status
python -m serial_gateway selftest
```

`vcom status` 是只读的：列出驱动、端口对和提醒，不会打开任何 COM 口。
