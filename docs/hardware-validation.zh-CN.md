# 硬件验收

[English](hardware-validation.md) | [简体中文](hardware-validation.zh-CN.md)

先使用可报废或可恢复的目标板，不在正式控制器上测试。

1. 确认两块板都是3.3V UART电平。接线前测量TX空闲电平；任一侧不兼容3.3V时加电平转换。
2. 每个接收端只连接一个发送端。连接ESP32 TX前，先断开或隔离目标板USB转串口芯片的TX。
3. 共地。每块板只使用一个电源，或采用已验证的隔离方案；不要把USB VBUS直接并到另一路5V。
4. 配置固件TX/RX及可选DTR/RTS引脚。未知用途的控制线保持禁用。
5. 先不接目标做回环测试，再做双向发送不同随机数据的双端全双工测试。
6. 用逻辑分析仪逐项验证启用的控制线：极性、时序、空闲状态和复位行为。
7. 传输中断开Wi-Fi，本次会话必须失败、输出停止，下一次会话不能出现旧数据。
8. 完成以上步骤后，才对比有线官方烧录和网络链路。

目标板若有启动使能或复位引脚，映射DTR/RTS前必须写清具体线路和极性。ASR PRO通过这些检查前，只作为计划中的示例。
